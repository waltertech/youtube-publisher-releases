# YouTube 发布工作台 1.3.0

本次新增：
- 首页“素材与文案设置”按钮打开弹窗，统一配置文案/封面识别关键词和兜底详情内容。
- 详情优先级为：原详情 → Hashtags → 兜底详情；前两项都空时才使用兜底，不改源文件。
- 素材列表展示原详情/Hashtags是否为空、详情来源和实际发布详情。
- 可轻量刷新未分配素材文案，不重新哈希大视频；已有任务文案保持不变。新增或已变更视频请重新扫描。
- 独立列出已选窗口总数、窗口名称/序号和频道，可逐项取消。
- “自动配置选择频道”只操作所选窗口的发现、权限核验、运行绑定三步，保留未选窗口配置。
- 显示当前已获取且已核验、启用、绑定就绪的可发布频道总数。

安装：确认无上传和操作后退出应用界面，打开DMG，把应用拖入Applications替换旧版，打开后首页版本应为v1.3.0。新版会检查并安全切换空闲旧后台；有任务则保留原后台并提示等待。

保存兜底文字后点击“刷新未分配素材文案”应用到已扫描素材，新增视频仍需点击“扫描素材”。

支持macOS 12+，包含arm64/x86_64。ad-hoc签名，无Apple Developer ID公证。Intel未实机验证，未执行真实频道上传。本次没有替换本机应用或修改实际用户台账。
