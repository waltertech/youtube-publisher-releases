# GitHub 1.3.0 发布步骤

当前没有上传或发布 GitHub Release。本目录的安装包可用于手动安装，在线更新签名待原作者完成。

## 必需的原作者签名

1. 使用现有发布者 Ed25519 私钥，生成当前 update.json 的签名。不得修改现有公钥或用新密钥代替。
2. 在本交付目录根目录执行（Python 环境需安装 cryptography）：

```sh
python3 "源码/YouTubePublisher-1.3.0/scripts/sign_update.py" sign --manifest "GitHub发布包/update.json" --key /secure/path/to/original-ed25519-key
python3 "源码/YouTubePublisher-1.3.0/scripts/sign_update.py" verify --manifest "GitHub发布包/update.json"
python3 "源码/YouTubePublisher-1.3.0/scripts/write_checksums.py" "GitHub发布包"
python3 "源码/YouTubePublisher-1.3.0/scripts/check_release.py" "GitHub发布包"
```

签名必须验证通过。update.json 的任一字节变化都需重新签名；更换 ZIP 还需更新 sha256 和 size。
完成后将 SIGNING-STATUS.json 的状态标记为 verified，重新生成本目录和交付根目录校验清单。
私钥不要放入本目录，不要上传 GitHub。

## Release 上传

在 https://github.com/waltertech/youtube-publisher-releases 创建 v1.3.0 的草稿 Release。
标题：YouTube 发布工作台 1.3.0。说明采用 RELEASE-NOTES.zh-CN.md。

附件：
- YouTubePublisher-Mac-1.3.0.dmg
- YouTubePublisher-Mac-1.3.0.zip
- YouTubePublisher-Source-1.3.0.zip
- update.json
- update.sig（原作者签名并验证通过后生成）
- SHA256SUMS.txt
- INSTALL.zh-CN.md
- BUILD-INFO.json

签名未完成时，不要将其发布为供旧客户端自动更新的 latest 正式版本。
发布后确认 ZIP 实际下载的 SHA-256 与清单一致，并核验 update.json / update.sig。

## 源码协作

发布仓库目前只承载说明和安装包。源码文件夹可以提交到双方实际开发仓库；配套 runtime-baseline ZIP 适合放在 Release 附件或单独的二进制依赖存储中。
Git 历史备份在“源码/YouTubePublisher-1.3.0.git.bundle”，包括原始提取基线及本次修改分支。
原作者 Swift 启动器源码尚未提供，因此交付源码附已编译启动器/运行时基线；详见源码 README。
