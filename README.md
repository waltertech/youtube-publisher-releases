# YouTube 发布工作台 · Mac

用于比特浏览器多窗口、多频道的素材扫描、发布计划、草稿和公开发布管理。

**[下载最新安装包](https://github.com/waltertech/youtube-publisher-releases/releases/latest)**

## 安装

1. 下载 DMG，把 YouTube发布工作台.app 拖入当前用户可写的 Applications 目录。
2. 安装并登录比特浏览器，启用 Local API（54345）。
3. 打开工作台，执行环境检测、频道配置，选择自己的素材文件夹并扫描。
4. 飞书同步可选，使用自己的飞书应用配置并授权。

支持 macOS 12+、Apple Silicon 和 Intel。已内置 Python、必要依赖、飞书 CLI 与本机发布工作流；不包含用户账号、素材、授权或历史发布记录。Intel 尚未实机验证。

## 在线更新

1.1.0 起，启动自动检查更新，也可使用工作台按钮或应用菜单的“检查更新”。确认下载后校验独立 Ed25519 签名和 SHA-256，暂停新任务，等待当前任务结束，备份配置和台账后安装并重新打开。启动验证失败会恢复旧应用。

1.0.0 需要先手动安装一次新版。需要联网访问 GitHub；无法连接时可手动下载 DMG。应用为 ad-hoc 签名，尚未 Apple Developer ID 签名与公证，首次运行可能需要在 macOS 隐私与安全性中手动允许。

## 数据与限制

数据保存在 `~/Library/Application Support/YouTube发布工作台`。退出界面后后台上传和已启用的调度仍会运行。跨电脑迁移应保留权威发布台账，避免同一素材重复上传。

工作流自动接入应用的本机执行器；比特原生 RPA 导入提供无凭据模板与手动导入说明。内核修复通过官方 API 请求切换到支持版本并验证，不支持时提示在比特客户端手动安装。

本仓库提供版本说明和安装包，并在 `source-v1.3.0/` 收录 1.3.0 共创业务源码、测试及打包脚本。安装包内包含运行所需程序文件，可以被提取查看。
