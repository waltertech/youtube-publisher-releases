# 换电脑与交付

仅复制 Automa JSON 不够。发布系统还依赖本机 Python 调度器、SQLite 去重台账、比特窗口与实际频道绑定、素材路径、桥接密钥和飞书授权。

## 另一位使用者，全新安装

1. 解压干净安装包；安装 Python 3.11 或更新版本（Windows 安装时选加入 PATH），安装并登录比特浏览器、打开本地 API。
2. macOS 双击“启动工作台.command”；Windows 双击“启动工作台.bat”。首次创建 Python 环境、安装依赖，输入此电脑的素材目录。
3. 在看板点“发现全部频道”。自动读取全部窗口和各账号频道；未登录或网络异常会显示具体原因。发现频道并不等于已通过发布验收。
4. 点“核验上传权限”，程序检查各频道权限和界面语言，自动建立本机执行器绑定。支持英文与中文界面；其他语言暂保持停用。无需逐个创建比特原生 RPA 任务，窗口由本机执行器通过比特本地 API 打开并核对频道 ID。
5. 飞书另装 lark-cli 并完成其应用配置，再在看板授权自己的账号、创建自己的台账。首次启动不执行上传。
6. 权限合格的频道可手动保存草稿；新执行器完成完整草稿验收后才能开启正式发布。手机号、验证码、身份验证需账号本人处理。

## 同一业务搬家

先停止旧电脑的上传，核实所有“结果待核查”任务，备份 publisher.sqlite3（使用 SQLite backup API）及素材，然后迁移数据库并更新路径、比特窗口和频道绑定。保留视频 SHA-256 与任务状态，不能从空数据库重新扫描后直接发布。不要同时在两台电脑对同一批素材独立调度；当前 SQLite 只保证本机唯一，跨机需共享一个调度服务。

干净安装包刻意不包含数据库、素材、飞书配置、认证信息、桥接密钥、历史日志和带密钥的 Automa 模板；因此不是“复制后立即发布”的成品。自动发现与权限核验能完成本机绑定，账号登录、手机号验证与飞书授权无法替别人自动完成。

当前版本改用本机执行器运行共用页面步骤，原生 Automa 模板仅作保留参考。安装包包含无凭据模板；不要分发“本机窗口流程”目录中的带本机密钥文件。Windows 启动程序已提供，尚未在实际 Windows 电脑验收。
